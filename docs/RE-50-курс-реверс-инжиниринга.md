# 🎓 RE-50: Реверс-инжиниринг с нуля
## Полный учебный курс в формате CS50 / Гарварда

> **Формат:** 24 недели (2 семестра), ~10–12 часов в неделю.
> **Стоимость:** $0 — все материалы бесплатные или с free-версией.
> **Язык:** русский, ресурсы — на русском и английском.
> **Философия CS50:** сначала головой (теория недели), потом руками (лаба + problem set), потом защищаешь работу (write-up). Никакого копипаста без понимания — иначе всё рухнет на неделе 8.

## Неделя 3–4. Ассемблер x86-64

### 📖 Лекции
- [beginners.re](https://beginners.re/) — «RE for Beginners» Юрьева: главы по x86 (бесплатно, есть русский оригинал)

- [Felix Cloutier x86 reference](https://www.felixcloutier.com/x86/) — справочник, держать открытым всегда

### Обязательные темы
1. Регистры и их «наложения» (`rax`→`eax`→`ax`→`al`)
2. Адресация `[rbx + rax*4 + 0x10]`
3. Стек, кадр функции, пролог/эпилог
4. Сравнение и переходы: `cmp`, `test` + `jcc` семейство
5. **Calling conventions:** Microsoft x64 (`rcx,rdx,r8,r9`) vs System V (`rdi,rsi,rdx,rcx,r8,r9`)
6. Как компилятор «переводит» if/for/while/switch

### 🧪 Лаба 2: Compiler Explorer (godbolt.org)
Протокол «предскажи и проверь» — 20 функций:
- 5 простых арифметических (`int add`, `int mul7` — найдёте lea-трюки)
- 5 с ветвлениями (if / if-else chain / тернарник)
- 5 циклов (for, while, do-while, вложенный)
- 5 с вызовами функций и структурами
Каждый раз: сначала письменно предсказываете asm → потом открываете godbolt → фиксируете расхождение в журнал.

### 📝 PSet2: Ручная декомпиляция

Бонус: напишите функцию `int count_char(const char *s, char c)` на чистом asm (nasm) и соберите программу с ней.

## Неделя 6. Формат PE

### 📖 Лекции
- [PE-спецификация Microsoft](https://learn.microsoft.com/windows/win32/debug/pe-format) — как справочник, читать выборочно
- Видео: разбор PE-формата (OALabs / LiveOverflow имеют выпуски; ищите «PE format explained»)

### Темы
DOS header → PE signature → COFF header → Optional header (ImageBase, EntryPoint) → секции (.text/.data/.rdata/.rsrc) → **IAT** → RVA vs VA vs file offset.

### 🧪 Лаба 4: PE руками
1. Возьмите любой свой `.exe`, откройте в **HxD**
2. Найдите `PE\0\0` вручную, распарсите COFF header байт за байтом (число секций, таймстамп)
3. Найдите таблицу секций, посчитайте смещение `.text`
4. Сверьте всё с выводом **DIE** / pestudio

### 📝 PSet4: Мини-парсер PE (Python)
Напишите скрипт на Python (struct, без pefile... а потом с pefile) который печатает:
- число секций, их имена и права
- AddressOfEntryPoint (RVA и VA)
- список импортируемых DLL и топ-10 функций

**Зачёт модуля 1:** вы пишете парсер PE сами — значит, формат поняли.

### ✅ Чек-пойнт
- [ ] Открываю hex и вижу структуру, а не кашу
- [ ] Объясняю, зачем нужна IAT и что сломается, если её испортить
- [ ] Понимаю, почему упаковщик ломает все правила нормального PE
