# Как устроен контент и как его править

Курс — это данные. Код ничего не знает о конкретных неделях: он читает `assets/curriculum.json` и `assets/drills.json`, вшитые в бинарь через `include_str!`.
Генераторов больше нет: **JSON — единственный источник истины**, правьте его напрямую (формат: UTF-8, отступ 1 пробел, без завершающего перевода строки — так его пишет `json.dumps(..., ensure_ascii=False, indent=1)`).

## `curriculum.json`

| Ключ | Что внутри |
|---|---|
| `course` | заголовок, подзаголовок (число недель проверяет тест), правила курса |
| `modules` | `id`, `name`, `icon` |
| `weeks` | `id` (`w7`, `w10-11`), `num`/`num_end`, `module`, `lectures[]`, `lab{title, steps[]}`, `psets[]`, `checkpoint[]`, `case` |
| `quizzes` | `id`, `week`, `module` (= модуль недели), `question`, ровно 4 `answers`, `correct` (с 0), `explain` |
| `achievements` | `id`, `name`, `desc`, `xp`, `when` — правило получения |
| `challenges` | `id`, `level`, `flag`, `sha256`, `sha256_exe`, `file`, `file_exe`, … |
| `flashcards`, `interview_questions`, `placement`, `rubric`, `diagrams`, `resources`, `topic_map`, `ethalon_writeups` | справочный материал |

PSet недели получает ключ `<week id>:<индекс>` (`w7:0`), шаг лабы — тот же формат.

### Правила ачивок (`when`)

Все указанные пункты должны выполняться одновременно:

```json
{ "when": { "psets": ["w3-4", "w5"], "quiz_modules": [1], "quiz_percent": 90, "weeks": ["w18"], "challenges": 5 } }
```

- `psets` — сданы все PSet перечисленных недель;
- `weeks` — недели отмечены закрытыми;
- `quiz_modules` — в этих модулях все квизы решены верно;
- `quiz_percent` — не менее N% всех квизов решены верно;
- `challenges` — решено не менее N встроенных челленджей.

Пустое правило запрещено: ачивку было бы невозможно получить.

### Разметка в тексте

В `lectures`, `case` поддержаны `**жирный**`, `*курсив*`, `` `код` `` и `[текст](https://…)` — ссылки открываются в браузере.

## Что проверяют тесты (`cargo test`)

`tests/content.rs`:
- id уникальны; недели, модули и квизы ссылаются друг на друга корректно; `quiz.module` совпадает с модулем недели;
- у квиза 4 разных ответа, `correct < 4`, есть `explain`; нет «все перечисленное»;
- **верный ответ нельзя угадать по длине или позиции:** самый длинный ответ верен не более чем в 35% вопросов, ответы в вопросе различаются по длине не более чем вдвое, позиции верного ответа распределены 15–35%;
- у каждой недели есть лекции, чек-пойнт, «проблема недели» и квиз; у каждого модуля есть квизы;
- каждая ачивка достижима: тест «выполняет всё» и проверяет, что выдано всё, а новичку — ничего;
- бинари челленджей: SHA-256 совпадают с JSON, `FLAG{…}` лежит в ELF и в PE открытым текстом — это проверка согласованности JSON и бинаря, а не защита от `strings`, список в `src/challenge_blob.rs` совпадает с `assets/challenges/`, у каждого бинаря есть исходник `.c`, ELF на Linux принимает решение и отвергает мусор;
- ключи адресных дриллов (RVA/VA/file offset) пересчитываются из текста вопроса.

`tests/ui_smoke.rs`: каждая вкладка и каждая страница недели рисуются без паник в тёмной и светлой темах на трёх размерах окна; egui не показывает предупреждение о совпадении id виджетов; **каждый символ данных и интерфейса есть в шрифтах** (иначе он превратится в квадрат).

`tests/docs.rs`: цифры в README, версия в CHANGELOG и подзаголовок курса не расходятся с данными.

## Добавить челлендж

1. Напишите `assets/challenges/<id>.c` (в успешной ветке `puts("Correct! FLAG{…}")`).
2. Соберите ELF и PE: `gcc -O0 -w <id>.c -o <id>` и `x86_64-w64-mingw32-gcc -O0 -w <id>.c -o <id>.exe`.
3. Добавьте `"<id>"` и `"<id>.exe"` в список `embed![…]` в `src/challenge_blob.rs`.
4. Занесите запись в `challenges` (`sha256` и `sha256_exe` — первые 16 hex-символов SHA-256 файлов).
5. Запишите решение в `tools/challenge_solutions.json` (строки, которые подаются на stdin).
6. `python3 tools/verify_challenges.py --rebuild && cargo test`.

## Символы и шрифты

Шрифты egui не содержат эмодзи новее Unicode 11, стрелок и рамок в основном шрифте. Приложение добавляет Noto Emoji и подключает Hack как запасной для пропорционального текста. Если тест `every_character_has_a_glyph` называет символ — замените его на существующий или добавьте шрифт в `src/ui/theme.rs` и `THIRD_PARTY_NOTICES.md`.
Селектор варианта `U+FE0F` (`⚙️`) шрифтами не рисуется — не используйте его.

## Ссылки

`python3 tools/check_links.py` проверяет все URL курса. По расписанию его запускает workflow `link-check`: он падает только на мёртвых ссылках (404/410, нет домена), отказы ботам и таймауты попадают в отчёт.
