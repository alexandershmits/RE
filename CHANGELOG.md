# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [7.2.0] — 2026-09-29

### Исправлено
- Светлая тема: подписи внутри полос прогресса («7% курса», «0/12», баллы оппонента, rubric) рисовались белым по светло-серому (контраст 1.22) — теперь подпись рядом с полосой.
- После ответа на квиз и входной тест варианты «отключались» и рисовались вполовину прозрачными, включая зелёный правильный и красный выбранный; теперь они не отключены (только не реагируют на мышь) и читаются в обеих темах. Входной тест использует общий список вариантов.
- Windows: паника или ошибка запуска (например, нет OpenGL 2.0) в релизной сборке без консоли оставались невидимыми — окно просто не появлялось. Теперь причина пишется в `crash.log` и показывается окном; код выхода при ошибке — 1.
- Тренажёр: фильтр по модулю не работал (любой модуль запускал все вопросы); «Завершить сессию» показывала «Вопрос 91/90».
- Кнопки A+/A− уменьшали текст (масштаб применялся к уже увеличенному стилю); при чистом профиле масштаб был 0.
- Прогресс писался на диск на каждом кадре (120 записей за 4 секунды) вместе с пятью копиями; запись теперь по флагу изменений, не чаще раза в 2 секунды, атомарная.
- Учёт времени приписывал до часа «фантомной» учёбы за каждый запуск после паузы.
- Симулятор регистров, задача 5: ключ был скопирован из задачи 1. Ответы теперь считает эмулятор.
- Генератор задач не принимал `0E7DAC03`, `0c`, `0x0C`; показывал смещение как `rip + 0xffffffffffffff9d`; соседние сиды давали одну и ту же задачу.
- Окно «Правило честности» не принимало текст, из-за чего problem set нельзя было сдать.
- Кнопки внутри вкладок («Открыть →», «Начать» на баннере re-certification) не переключали вкладку.
- Поле флага сдавало пустой флаг при каждом клике; подсказки и «ставки» карточек челленджей делили одно состояние.
- Импорт прогресса из буфера не мог сработать; экспорт на Windows писал в текущий каталог (нет `HOME`).
- `cargo test` писал в настоящий `$HOME`.
- XP можно было фармить повторными кликами (недели, лабы, симуляторы, дриллы, рабочие тикеты).
- Пять ачивок были недостижимы (1650 XP); правила ачивок теперь лежат в данных и проверяются тестом достижимости.
- Re-certification не возвращала ошибочные вопросы в слабые темы, а её уведомление исчезало мгновенно.
- Ответы квизов: правильный ответ был самым длинным в 82% вопросов (теперь 24%); исправлены неверные ключи `q_mal2`, `q_mal4`, `q_w39b`, `q_w46a`.
- Светлая тема была нечитаема; эмодзи 🩸 🧪 🥋 и стрелки рисовались квадратами; счётчики на дашборде обрезались.
- Ollama-запросы и генератор челленджей блокировали интерфейс (до 2 минут); теперь работают в фоне.
- «Сутки» для серии, дневного лимита XP и ре-сертификации считались по UTC (в UTC+3 граница дня приходилась на 03:00, в UTC+10 — на 10:00); теперь по местному времени.
- Учёт времени отбрасывал паузу дольше 5 минут целиком (6 минут чтения без ввода давали 0, 4:59 — полностью); теперь одна пауза засчитывается не более чем 5 минутами.
- Хранилище: второе окно затирало прогресс первого (теперь блокировка `progress.json.lock`, второе окно только читает); запуски без изменений вытесняли старые бэкапы одинаковыми; файл более новой схемы молча понижался и перезаписывался; после переименования не сбрасывался каталог (`fsync`); без каталога настроек прогресс молча не сохранялся.
- Тема: при светлой теме ОС и сохранённой тёмной палитра выходила тёмной на светлых визуалах (контраст 1.4–3.1), масштаб шрифта пропадал; теперь выбор из профиля сильнее системной темы.
- Импорт прогресса принимал любой JSON (`{}`, чужой файл) и обнулял XP и журнал; теперь нужен хотя бы один известный ключ. Файл прогресса с BOM (Блокнот «UTF-8 с BOM») не считается повреждённым; уровень карточки вне диапазона не отправляет весь файл в карантин.
- «Слабые темы» не видели новую ошибку в ранее решённом вопросе; «Повторить всё равно» двигало расписание карточек (три «Знаю» за день выпускали ошибку); подсказка тренажёра называла неверные интервалы.
- Уведомления при запуске (файл повреждён, открыто в другом окне, схема новее) держатся на экране до закрытия и рисуются как предупреждения; неверный флаг, провал ре-экзамена и ошибка генератора больше не выглядят как успех.
- Разметка съедала `*` в C-коде лекций (`char *p`, `(*p)`); в шагах лаб, PSet и чек-пойнтах были видны сырые `` ` `` и `**`.
- Боковое меню не прокручивалось: при крупном шрифте последние вкладки уходили за экран. Переключение вкладок сбрасывало идущий квиз; повторная отправка ответа оппоненту показывала ответ модели на прежний текст. Пути с пустыми `APPDATA`/`HOME` и относительным `XDG_CONFIG_HOME` давали каталог настроек от текущей папки.
- Эмулятор: `push`/`pop` не меняли `rsp`. Дриллы: `cmovne` с непосредственным операндом, «LEOS» вместо «ELOS», xorshift64 назван xorshift32, спорный `gs:[0x30]` для Go, два эталонных Python-скрипта не запускались; в задаче про DOS-заголовок `e_lfanew` был указан тремя разными значениями.
- Эталонные разборы lv3a, lv2b, lv3c не совпадали с бинарями (константа хеша, формула, тип ввода); диаграмма кадра Microsoft x64 без shadow space; ошибки в интервью (UPX, CFG, VMENTRY), в инструментальных подсказках (F4 в x64dbg, `FUN_*` вместо `sub_*` в Ghidra, `ldd` на недоверенных бинарях), мёртвые и неверные ссылки (crkmy, PMAT-course), опечатки.
- Оппонент: маркеры «пустого ответа» совпадали с терминами темы и отнимали баллы у верных ответов; ключевое слово `va` совпадало с любым «value».
- Расхождения контента с приложением: интервалы карточек, описания ачивок «Фундамент» (бывшая «Владею C»), «Студент pwn.college» и «Скальпель»; в вопросе о регистрах общего назначения верными были два ответа.
- Мёртвые ссылки в CI не находились: workflow проверял поле, которого нет в данных.

### Добавлено
- `crash.log` (паники любого потока и ошибки запуска, с ротацией) и окно с причиной на Windows; подсказка про OpenGL.
- Проверка контраста по отрисованным фигурам: цвет каждого текста против подложки под ним на всех вкладках, неделях и состояниях в обеих темах; тест «ответы квиза не прозрачны».
- `deny.toml` и `cargo-deny` в CI (лицензии, запрещённые источники); workflow `audit` (советы RustSec раз в неделю и на PR, меняющие зависимости); еженедельный прогон CI.
- Карточки с интервальным повторением; ошибки квизов автоматически становятся карточками.
- Правила ачивок в `curriculum.json`; 11 новых ачивок (недели 22, 41–48).
- 25 пунктов лекций, 44 пункта чек-пойнтов, 18 квизов и шаги лаб для недель, где их не было; у каждого модуля есть квизы.
- Разметка в тексте курса: `**жирный**`, `*курсив*`, `` `код` ``, кликабельные ссылки.
- Восстановление из бэкапа при повреждении файла прогресса (в т.ч. не UTF-8, например UTF-16 из Блокнота) с уведомлением; если файл не читается по другой причине, сохранение отключается, чтобы его не затереть; переменные `RE50_CONFIG_DIR` и `RE50_EXPORT_DIR`.
- Диалог импорта прогресса, автосохранение журнала, антифарм XP-генератора (лимит в день), защита оппонента от «набора ключевых слов».
- SHA-256 бинарей челленджей в интерфейсе и в `TASK.txt`; `tools/verify_challenges.py`, `tools/check_links.py`.
- Генератор челленджей сам решает каждый вариант (self-solve): решение обязано выдать флаг, заведомо неверный ввод — нет.
- `tools/test_tools.py` (классификация ссылок, эталонные Python-ответы дриллов, self-solve генератора); тесты «на экране нет сырой разметки», «сохранённая тема сильнее темы ОС», «в курсиве нет кода».
- Тесты: с 13 до 170+ (контент, UI без окна, хранилище, эмулятор, ачивки); проверка палитры на WCAG AA; проверка покрытия глифами.
- CI: `fmt`, `clippy -D warnings`, тесты на трёх ОС, пересборка челленджей; релиз с контрольными суммами; Dependabot.
- LICENSE, THIRD_PARTY_NOTICES, docs/CONTENT.md.

### Изменено
- Тест покрытия глифами использует `skrifa` вместо `ttf-parser` (последний больше не поддерживается: RUSTSEC-2026-0192); `windows-sys` — прямая зависимость только для Windows.
- CI: прогоны `main` и релиза не отменяются новым коммитом (отменяются только устаревшие прогоны PR); Dependabot собирает мелкие обновления Rust-крейтов в один PR.
- eframe/egui 0.29 → 0.36 (MSRV 1.95); новая зависимость `chrono` (только `clock`) — для часового пояса.
- Крейт разделён на библиотеку и бинарь; `state.rs` и `ui.rs` разбиты на модули; единый ГПСЧ вместо пяти копий.
- 31-МБ файл `challenge_blob.rs` из hex-литералов заменён на `include_bytes!` (холодная компиляция: 36 с → 7 с, память: 3.5 → 1.2 ГБ). Windows-бинари челленджей теперь лежат в репозитории.
- Формат `progress.json` — схема v2, детерминированный порядок ключей; файлы старых версий мигрируют автоматически (XP за недели, лабы, PSet, rubric и тикеты повторно не выдаётся, незакрытые ошибки квизов становятся карточками).
- Версия крейта согласована с тегами релизов (была 1.0.0 при тегах v7.x).
