# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [7.2.0] — 2026-09-29

### Исправлено
- Тренажёр: фильтр по модулю не работал (любой модуль запускал все вопросы); «Завершить сессию» показывала «Вопрос 91/90».
- Кнопки A+/A− уменьшали текст (масштаб применялся к уже увеличенному стилю); при чистом профиле масштаб был 0.
- Прогресс писался на диск на каждом кадре (120 записей за 4 секунды) вместе с пятью копиями; запись теперь по флагу изменений, не чаще раза в 2 секунды, атомарная.
- Учёт времени приписывал до часа «фантомной» учёбы за каждый запуск после паузы.
- Симулятор регистров, задача 5: ключ был скопирован из задачи 1. Ответы теперь считает эмулятор.
- Генератор задач не принимал `0E7DAC03`, `0c`, `0x0C`; показывал смещение как `rip + 0xffffffffffffff9d`; соседние сиды давали одну и ту же задачу.
- Окно «Правило честности» не принимало текст, из-за чего problem set нельзя было сдать.
- Кнопки внутри вкладок («Открыть →», «Начать» на баннере re-certification) не переключали вкладку.
- Поле флага сдавало пустой флаг при каждом клике; подсказки и «ставки» карточек челленджей делили одно состояние.
- Импорт прогресса из буфера не мог сработать; экспорт на Windows писал в текущий каталог (нет `HOME`).
- `cargo test` писал в настоящий `$HOME`.
- XP можно было фармить повторными кликами (недели, лабы, симуляторы, дриллы, рабочие тикеты).
- Пять ачивок были недостижимы (1650 XP); правила ачивок теперь лежат в данных и проверяются тестом достижимости.
- Re-certification не возвращала ошибочные вопросы в слабые темы, а её уведомление исчезало мгновенно.
- Ответы квизов: правильный ответ был самым длинным в 82% вопросов (теперь 24%); исправлены неверные ключи `q_mal2`, `q_mal4`, `q_w39b`, `q_w46a`.
- Светлая тема была нечитаема; эмодзи 🩸 🧪 🥋 и стрелки рисовались квадратами; счётчики на дашборде обрезались.
- Ollama-запросы и генератор челленджей блокировали интерфейс (до 2 минут); теперь работают в фоне.
- Мёртвые ссылки в CI не находились: workflow проверял поле, которого нет в данных.

### Добавлено
- Карточки с интервальным повторением; ошибки квизов автоматически становятся карточками.
- Правила ачивок в `curriculum.json`; 11 новых ачивок (недели 22, 41–48).
- 25 пунктов лекций, 44 пункта чек-пойнтов, 18 квизов и шаги лаб для недель, где их не было; у каждого модуля есть квизы.
- Разметка в тексте курса: `**жирный**`, `*курсив*`, `` `код` ``, кликабельные ссылки.
- Восстановление из бэкапа при повреждении файла прогресса (в т.ч. не UTF-8, например UTF-16 из Блокнота) с уведомлением; если файл не читается по другой причине, сохранение отключается, чтобы его не затереть; переменные `RE50_CONFIG_DIR` и `RE50_EXPORT_DIR`.
- Диалог импорта прогресса, автосохранение журнала, антифарм XP-генератора (лимит в день), защита оппонента от «набора ключевых слов».
- SHA-256 бинарей челленджей в интерфейсе и в `TASK.txt`; `tools/verify_challenges.py`, `tools/check_links.py`.
- Тесты: с 13 до 140+ (контент, UI без окна, хранилище, эмулятор, ачивки); проверка палитры на WCAG AA; проверка покрытия глифами.
- CI: `fmt`, `clippy -D warnings`, тесты на трёх ОС, пересборка челленджей; релиз с контрольными суммами; Dependabot.
- LICENSE, THIRD_PARTY_NOTICES, docs/CONTENT.md.

### Изменено
- eframe/egui 0.29 → 0.36 (MSRV 1.95).
- Крейт разделён на библиотеку и бинарь; `state.rs` и `ui.rs` разбиты на модули; единый ГПСЧ вместо пяти копий.
- 31-МБ файл `challenge_blob.rs` из hex-литералов заменён на `include_bytes!` (холодная компиляция: 36 с → 7 с, память: 3.5 → 1.2 ГБ). Windows-бинари челленджей теперь лежат в репозитории.
- Формат `progress.json` — схема v2, детерминированный порядок ключей; файлы старых версий мигрируют автоматически (XP за недели, лабы, PSet, rubric и тикеты повторно не выдаётся, незакрытые ошибки квизов становятся карточками).
- Версия крейта согласована с тегами релизов (была 1.0.0 при тегах v7.x).

### Удалено
- `tools/gen_curriculum.py`, `tools/gen_curriculum_v2.py` (не запускались: пути `/home/agentuser`, не отражали текущий JSON) и `tools/gen_embedded.py` (терял 15 из 30 файлов).
